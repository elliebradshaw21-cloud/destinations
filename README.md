# Destinations
Holiday destination webpage built with HTML and CSS as part of my Interactive Computing course at Ulster University

## About the project
We were asked to design a website of our choosing, my group chose a travel website and I was in charge of completing the destinations page. I decided on the layout and researched the information on the page and matched it to the colour and styling that our group agreed on. 

## Built using 
- HTML
- CSS 

## What I learned 
 - how to collaborate with other members of my team to ensure a            consistent design across all web pages
 - Planning the styling and layout of the page with CSS
 - Researching and presenting information in a clear way for users
